← Studio · 打开网页网格编辑器

用自己的 Agent 准备素材，再继续编辑。

技能包适用于你自己的 Codex、Claude Code 或 subagent。默认离线，不调用宿主 Agent、不上传素材、不安装依赖，也不包含仓库角色模型、私有素材或官方 Core。

下载本地技能包 0.1.0 ZIP · SHA-256 校验文件

  1. 解压后先读 SKILL.md、README.md 和许可。脚本需要你已安装的 Node 22.12+；没有 npm 依赖。
  2. 按素材规范准备真实分层 PSD 或带角色、坐标及哈希的 PNG 图层。自动网格和眼嘴预设是起始近似，仍需检查真实像素。
  3. 生成或保存可编辑的 project.mesh2d.json，在网页编辑器打开，修改基础网格或参数端点，再保存并重开。
  4. 另行导出运行时模型包：moc3、model3.json、贴图、测试动作和验收记录。保留源项目，方便继续修改。

当前导出范围：一个实际运动参数、两个线性关键形、扁平 ArtMesh。多参数组合、旋转、层级、蒙版和物理会明确拒绝。技能的离线导出生成候选包，须由合法获得的官方 Core 和实际浏览器画面、动作检查验收。

两个文件用途不同：mesh2d 源项目可以继续编辑；仅有 moc3 的既有模型可播放、调参数，不承诺恢复完整编辑工程或无损再次导出。当前网页打开 editable-project.zip 时，请先解压并选其中的 project.mesh2d.json。

脚本不自动下载 SDK。所需官方依赖由你合法取得并确认条款；MIT 实验写入器使用上游逆向格式资料，不是官方 Cubism 导出器。私有素材在远程网页中打开是一个单独的目的地决定，也可使用你自己的本地编辑器。
