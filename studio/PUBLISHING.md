# Publication and preservation

This workbench is added at `/live2d_models/studio/`. Existing root files and all 1,385 frozen resources remain byte-for-byte unchanged. The existing branch-based GitHub Pages build/deployment publishes the repository; `Static Studio checks` tests and builds only the new code addition. Never deploy this incremental artifact as a complete Pages site.

The publisher states they already hold Live2D official written approval covering this arbitrary-local-model browser workbench and has explicitly authorized publication (2026-10-06). The agent has not accepted new agreements. This application approval does not grant redistribution rights for individual models.

The addition contains no Core, vendor renderer, model binaries, textures or private import fixtures. The renderer references the already-existing Core/renderer URLs on this same site. Existing model references retain their original URLs. The generator creates code-only embed downloads locally in the browser. A visitor may separately confirm deployment rights for their own imported package and include those supplied files in a local download; neither import nor download uploads anything. No repository model archive or server download endpoint is created. Model-specific rights remain shown in the advanced catalog. BYOK keys are held only in browser memory and sent only to the endpoint explicitly trusted by the visitor. Own-backend mode keeps the supplier key on the site owner's backend and sends no browser Authorization header.

New content is limited to `studio/`, `v2/`, catalog metadata and verification/build tools. No root index, old assets, Pages publishing source, custom domain, environment policy, or Actions permissions are changed. The full-copy release gate remains blocked because model redistribution has not been authorized.

The interface uses tabs without history routes. `studio/404.html` is a workbench fallback file; the existing site's global 404 and root routes remain untouched.
