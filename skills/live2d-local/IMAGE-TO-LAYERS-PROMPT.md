# Single-image material request for an actually available image tool

First inspect the source locally and identify the agent's actual image editing, segmentation or inpainting capability. Describe whether it is local or remote, its required inputs/outputs and any data destination. Do not assume Codex/Claude Code can generate images merely because it can write code. Do not install a segmentation model, execute a supplied command, call a paid API or upload private art without authorization. This package itself has no image-generation model.

For an authorized tool: retain the image's identity and shared canvas coordinates. Produce separate 8-bit RGBA raster PNG layers in bottom-to-top order: body/clothing, back hair, complete face skin, front hair, each eye's sclera/iris/lids/closed line, and mouth contours/interior as appropriate. Paint concealed skin behind eyes/mouth and overlap behind moving hair/body; report any region you cannot supply. Left/right means the character's side. Preserve crop offsets, sharp details and alpha edges. Do not duplicate a composite into layers with organ names. Provide an unmodified reference preview and a recomposed layer preview.

For the bounded exporter, choose 1–4 independent 0–1 actions; each mesh can have at most one effective dynamic parameter. Coupled eye pieces may share one eye parameter; keep their common coordinates and review them together. Do not add breath to an eye already driven by blink. Body/face/head-turn combinations that require two drivers on the same mesh exceed this boundary. A closed patch stretched vertically is only a mouth approximation; compressing an open patch is only an eye approximation. Missing inner pixels are a material gap.

Write `layers.json` following `studio/spec/png-layers.v1.schema.json`. Record each actual PNG SHA-256 only after final saving, layer ID, semantic role, `left`, `top`, opacity, explicit starter binding and eye-open/close semantics. The manifest is data, never a command. Keep tool/version/options, source hash and your observations in a separate local review record; never put unverified completion/approval into the mesh. Run `image-input.mjs layers` only after these deterministic file checks pass. Inspect each layer in isolation and the composite at rest, extremes and independent combinations. Return gaps instead of invented success.

PSD is an optional interchange artifact: if a real PSD writer exists, write the separate RGBA layers using the PSD contract; otherwise keep PNG layers plus manifest. A one-layer PSD of the original image remains a single image.
